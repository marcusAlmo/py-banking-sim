# Python Banking Simulator (`py-banking-sim`)

A modular Python-based simulation system for banking operations, account transactions, ledger management, and financial workflows.

## Features (Planned)
- Account management (Checking, Savings, Credit)
- Transaction processing & ledger auditing (Deposits, Withdrawals, Transfers)
- Concurrency & rate-limiting protection
- Automated transaction logs & metrics reporting

## Getting Started

### Prerequisites
- Python 3.10+

### Setup
```bash
# Clone repository
git clone https://github.com/marcusAlmo/py-banking-sim.git
cd py-banking-sim

# Create and activate virtual environment
python3 -m venv .venv
source .venv/bin/activate

# Install dependencies (if requirements.txt exists)
# pip install -r requirements.txt
```
